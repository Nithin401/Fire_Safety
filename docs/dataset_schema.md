# Dataset Schema

All CSV files generated by `tools/flame_data_logger.py` follow this strict schema:

| Column | Type | Description |
|--------|------|-------------|
| `pc_timestamp` | ISO 8601 String | Timestamp applied by the laptop receiving the data. |
| `esp_timestamp_ms` | Integer | Millis() counter from the ESP8266. |
| `device_id` | String | Identifier for the detection node (e.g., `ESP1`). |
| `room_id` | String | Location identifier (e.g., `ROOM_1`). |
| `flame_raw` | Integer | 10-bit analog reading from the IR flame sensor (0-1024). |
| `session_id` | String | Unique experiment identifier (e.g., `NORMAL_001`). |
| `condition` | String | Ground-truth label (`NORMAL`, `FLAME`, `RECOVERY`, `NOISE`, `UNKNOWN`). |
| `distance` | String | (Optional) Distance to fire source. |
| `orientation` | String | (Optional) Angle/orientation of sensor relative to fire. |
| `notes` | String | (Optional) Qualitative experimental notes. |

*Note: No data is fabricated. Missing or invalid values are recorded as-is and handled during the preprocessing stage.*
